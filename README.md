# 🌟 전국 포켓몬 도감 (National Pokédex Web App)

> 서버 구동 없이 브라우저에서 즉시 실행되며, GitHub Pages를 통해 무료 배포 가능한 고품질 반응형 포켓몬 도감 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **전국도감 1~9세대 완벽 지원 (총 1,025마리)**
   - 1세대 관동 지방(#0001 이상해씨)부터 9세대 팔데아 지방(#1025 복숭악동)까지 전 세대 수록
   - 세대별 탭 원클릭 필터링 (1세대~9세대)

2. **초고속 한국어 실시간 검색 & 정렬**
   - 포켓몬 한국어 이름(예: `피카츄`), 영문 이름(`Pikachu`), 도감 번호(`25`, `#0025`) 실시간 검색
   - 18개 속성(노말, 불꽃, 물, 풀, 전기, 드래곤 등) 타입별 필터링
   - 도감 번호순(낮은순/높은순), 이름 가나다순 정렬

3. **고해상도 카드 & 직관적인 UI**
   - 닌텐도/포켓몬 공식 일러스트레이션(Official Artwork) 적용
   - 포켓몬 주 속성 색상에 맞춘 모던 카드 디자인
   - 다크 모드 / 라이트 모드 테마 전환 지원

4. **풍부한 상세 정보 모달 (Detailed Modal)**
   - **실제 포켓몬 울음소리 재생**: 오디오 재생 버튼 클릭 시 PokeAPI 공식 최신 울음소리 사운드 재생
   - **한국어 도감 설명**: 공식 버전 한국어 도감 설명 텍스트
   - **신체 스펙**: 키(m), 몸무게(kg), 분류(예: 씨앗포켓몬)
   - **종족값 능력치 바**: HP, 공격, 방어, 특수공격, 특수방어, 스피드, 능력치 총합 게이지바
   - **이전/다음 포켓몬 네비게이션**: 좌우 화살표 버튼 및 키보드 방향키(`←`, `→`), `ESC` 닫기 지원

5. **나만의 즐겨찾기(찜) 기능**
   - 하트 버튼으로 마음에 드는 포켓몬 찜하기
   - 브라우저 자체 `localStorage`에 안전하게 저장되어 재접속 시에도 유지
   - '내 즐겨찾기' 필터 버튼으로 찜한 포켓몬만 모아보기 가능

6. **100% 서버리스 정적 웹 (Static Site)**
   - 별도의 Node.js, Python 등의 백엔드 서버 없이 동작
   - `index.html` 파일을 더블 클릭하여 크롬/사파리 브라우저에서 바로 열람 가능

## 🚀 GitHub Pages 무료 배포 방법 (`github.io`)

1. **GitHub 저장소(Repository) 생성 후 업로드**:
   ```bash
   git init
   git add .
   git commit -m "feat: 포켓몬 도감 웹앱 완성"
   git branch -M main
   git remote add origin https://github.com/<본인-깃허브-아이디>/<저장소-이름>.git
   git push -u origin main
   ```

2. **GitHub Pages 활성화**:
   - GitHub 해당 저장소 페이지 접속 -> **Settings** 클릭
   - 좌측 메뉴에서 **Pages** 선택
   - **Build and deployment** 항목의 **Branch**를 `main` (또는 master) / `/ (root)` 선택 후 **Save** 버튼 클릭

3. **완료!**:
   - 약 1분 후 `https://<본인-깃허브-아이디>.github.io/<저장소-이름>/` 주소로 전 세계 어디서든 모바일과 PC에서 즉시 접속 가능합니다.
